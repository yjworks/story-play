# 이야기 파일 형식

> 새 파일을 만들면 `stories/files.js`에 넣고 `node tools/build-index.mjs`로 색인(`stories/index.js`)을 다시 만든다. 앱은 색인만 먼저 받고, 이야기를 열 때 그 파일만 받는다. `node tools/check-stories.mjs`가 색인이 최신인지도 확인한다.

한 모음 = `stories/<파일>.js` 하나. `export default [ {이야기}, ... ];`

```js
{
  id: 'fox-stork',              // 영문 소문자-하이픈, 전체에서 유일
  source: '이솝우화',            // 모음 이름 = 목록의 태그 이름 (모음 안에서 모두 같게)
  emoji: '🦊',                  // 목록 아이콘 1개
  title: '여우와 두루미',        // 12자 이하 (목록에서 한 줄)
  scene: { bg: 'house', items: ['🦊', '🥣', '🦢'] },
  //  bg: forest | field | sky | river | house | village | palace | night
  //  items: 2~4개, 왼쪽→오른쪽 배치. Unicode 13 이하의 흔한 이모지만(삼성 기기 표시 보장)
  outro: [
    '여우와 두루미 이야기, 재미있었나요?',                 // 1: 인사 (이야기마다 조금씩 다르게)
    '내가 두루미라면, 여우에게 똑같이 갚아 주었을까요?',     // 2: 주인공 입장이 되어 보는 질문
    '친구를 초대한다면, 무엇을 준비하고 싶나요?',           // 3: 아이 자신의 경험·생각을 묻는 질문
  ],
  cast: {
    해설: { voice: 'F2', speed: 0.95 },   // 해설은 꼭 있어야 하고 speed 0.95
    여우: { voice: 'M3', speed: 1.1 },    // 인물 이름은 띄어쓰기 없이 6자 이하
    두루미: { voice: 'F4', speed: 0.95 },
  },
  //  voice: F1~F5, M1~M5 중에서, 한 이야기 안에서는 모두 다르게. speed 0.85~1.25
  //  age(선택): 'child' | 'normal' | 'adult' | 'old' — 음 높이와 빠르기를 나이에 맞게 조금 바꿈.
  //    없으면 이름으로 짐작(아이·꼬마·아기·소년·소녀·막내·손자·손녀 → child, 할머니·할아버지·할멈·영감·노인 → old, 나머지 normal)
  lines: [
    ['해설', '옛날 옛날, 깊은 숲속에 꾀돌이 여우가 살았어요.'],
    ['여우', '<laugh> 어라? 수프가 맛이 없니?'],
    // ...
  ],
},
```

## 글쓰기 기준
- 대상: 초등 저학년 이하. 한 줄은 짧게(60자 이하), 쉬운 낱말, 소리 흉내 말(보글보글, 쿵쿵)과 되풀이.
- 한 편 25~30줄. 원전의 주요 흐름은 유지하고, 문장은 모두 새로 씀(시중 번역본·동화책·애니메이션 문장과 설정 사용 금지. 특히 디즈니 판의 이름·노래·장면 금지).
- 무서운 장면(잡아먹힘, 죽음, 신체 훼손, 불태움 등)은 순화: 도망감, 혼쭐남, 잘못을 뉘우침 등으로.
- 해설은 "~했어요/~했지요/~답니다" 말투. 인물 대사는 따옴표 없이.
- 마지막 해설 한 줄은 이야기의 교훈을 아이 눈높이로.
- 표현 태그 `<laugh>` `<sigh>` `<breath>`는 한 편에 0~3개, 대사 맨 앞에만.
- 모든 문장은 마침표·물음표·느낌표로 끝냄.

## 영문 모드 원고 (stories/en/*.js)
- 영어 학습용(한국 초등 저학년, 영어 초급). `export default { '<이야기 id>': { title, names, outro, lines } }`
- `lines`의 첫 칸은 한국어 이야기 `cast`의 이름 그대로(목소리를 함께 씀), `names`에 화면에 보일 영어 이름.
- 이야기당 18~24줄, 문장은 되도록 8단어 이하(최대 12), 초급 낱말·단순 현재/과거, 되풀이 표현.
- 새 파일은 `stories/files.js`의 `EN_FILES`에 넣고 색인을 다시 만들 것. 원고가 있는 이야기만 영문 모드 목록에 나옴.

## 시 (poem: true, 예: stories/yun.js)
- 원문 그대로 한 행 = `lines` 한 줄, 연 구분은 `['해설', '']`. 화면에서는 행마다 줄바꿈·가운데 정렬, 연이 바뀌면 조금 더 쉼.
- 퍼블릭 도메인 원문만(출처를 파일 머리에 적음). 표기를 고치지 않음. 마무리 질문(outro)만 자체 작성.
- 줄 수·문장부호·길이 규칙은 적용하지 않음(검사 도구가 건너뜀).

## 청소년 (age: 'teen')
- 표지·목록의 `어린이 / 청소년`에서 고름. 청소년 원고는 한국어만(영문 모드에서는 어린이만).
- 원문 낭독(prose: true, 예: stories/teen-modern.js): 퍼블릭 도메인 원문을 문장 단위로, 빈 줄('')은 문단 구분. 한국 작가는 1963년 이전 사망 + 미국 기준(1931년 이전 출판, 또는 1996-01-01에 한국에서 이미 만료)을 둘 다 확인.
- 각색(예: stories/teen-a.js): 같은 형식, 해설은 "~했다/~했습니다" 문어체, 마무리 질문은 주제·인물/표현·삶과 사회 순서.
